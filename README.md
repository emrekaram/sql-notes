# sql-notes

SQL (T-SQL / Microsoft SQL Server) scripts and personal notes written while learning. Comments are in Turkish.

**Status:** Learning archive · **Stack:** Microsoft SQL Server, T-SQL

## Files

| File | Contents |
|---|---|
| `SQL Intro.sql` | DML basics on Northwind: `SELECT`, filtering, sorting |
| `SQL Intro Derli.sql` | Compiled query examples from the intro lessons |
| `SQL Functions.sql` | User-defined functions: scalar, inline and multi-statement table-valued |
| `SQL Plus+.sql` | Stored procedures |
| `SQL Trigger,Index,Transaction.sql` | Procedures with output parameters, triggers, indexes and transactions |
| `SQL Question's.sql` | Practice questions and solutions on Northwind |
| `SQL My Note's.sql` | Personal SQL cheat sheet (English) |

## Running

Open the scripts in SQL Server Management Studio or Azure Data Studio and run them against a practice database (the examples use the Northwind sample database).
